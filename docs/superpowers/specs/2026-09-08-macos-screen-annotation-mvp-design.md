# macOS 屏幕标注小工具 MVP 设计规格

## 1. 目标

开发一个仅在本机运行的原生 macOS 菜单栏小工具。用户通过固定全局快捷键进入绘图模式，在主显示器上绘制箭头、矩形框和单行文字；退出绘图模式后，标注继续显示，但鼠标事件穿透到下方应用。

本项目的工作名称为 `ScribbyMac`。工作名称只用于工程、目标产物和测试，不代表最终品牌决定。

## 2. 支持范围

- 仅支持 Apple Silicon（`arm64`）。
- 最低系统版本为 macOS 13。
- 第一版仅支持主显示器。
- 保证支持 macOS 桌面和普通应用窗口。
- 测试至少一个 macOS 标准全屏应用。
- 对全屏游戏和特殊 Metal 窗口仅作尽力兼容，不作为首版验收条件。
- 交付完整 Xcode/Swift 源码和可直接双击运行的本地 `.app`。
- `.app` 使用本地构建或 ad-hoc 签名，不制作 `.dmg`，不做 Developer ID 公证或 Mac App Store 配置。

## 3. 明确不在首版实现的内容

- 开机启动。
- Premium、账号、许可证、付费或网络功能。
- 遥测、崩溃上报或远程日志。
- 保存、自动恢复、导入或导出标注。
- 多显示器绘图。
- 自定义全局快捷键和设置窗口。
- 自由画笔、橡皮擦、直线、椭圆和图片粘贴。
- 标注的选择、移动、缩放或单独删除。
- 重做。
- 截图、冻结画面和标注跟随其他应用窗口。

## 4. 技术方案

采用纯原生 Swift、AppKit 和 Core Graphics，不引入第三方依赖。

- AppKit 负责应用生命周期、菜单栏、透明窗口、悬浮工具栏、文字编辑和鼠标事件。
- Core Graphics 负责箭头、矩形和文字渲染。
- Carbon `RegisterEventHotKey` 负责注册固定全局快捷键 `Command + Shift + D`。
- `NSUndoManager` 或等价的应用内命令栈负责撤销。
- Xcode 工程包含应用 target 和单元测试 target。

首版不使用 SwiftUI、Metal、ScreenCaptureKit、Accessibility API 或网络框架。

## 5. 组件边界

### 5.1 `AppDelegate`

- 启动菜单栏应用并确保不显示 Dock 图标。
- 组装各控制器并处理应用退出。
- 记录进入绘图模式前的前台应用，以便退出绘图模式后恢复焦点。

### 5.2 `StatusMenuController`

管理菜单栏图标及以下菜单项：

- 开始绘图／结束绘图。
- 显示标注／隐藏标注。
- 清空全部。
- 退出。

菜单标题必须随当前状态更新。没有标注时，“显示／隐藏标注”和“清空全部”不可用。

### 5.3 `GlobalHotKeyController`

- 注册和注销 `Command + Shift + D`。
- 将热键事件转换成单一的“切换绘图模式”动作。
- 注册失败时返回明确错误，不监听全部键盘输入。

### 5.4 `OverlayController`

- 管理主显示器上的透明覆盖窗口。
- 管理绘图、穿透显示和隐藏三个状态。
- 进入绘图模式时显示画布、红色边框和工具栏。
- 退出绘图模式时隐藏边框和工具栏，并将覆盖窗口设为鼠标穿透。
- 主显示器参数变化后，在下次进入绘图模式时重新计算窗口 frame。

### 5.5 `OverlayWindow`

- 无边框、透明背景、无阴影。
- 覆盖主显示器完整 frame。
- 使用能够加入所有 Spaces 并作为标准全屏辅助窗口显示的 collection behavior。
- 绘图状态接收鼠标事件；穿透状态设置 `ignoresMouseEvents = true`；隐藏状态移出屏幕窗口列表。
- 窗口层级高于普通应用窗口，但不尝试覆盖系统安全界面、菜单栏或受保护内容。

### 5.6 `DrawingCanvasView`

- 将鼠标按下、拖动和抬起转换成草稿图形及已提交标注。
- 实时绘制当前草稿。
- 负责展示内联单行文字输入框。
- 从 `AnnotationStore` 读取已提交标注并进行重绘。
- 不包含菜单栏、窗口状态或磁盘存储逻辑。

### 5.7 `ToolbarPanelController`

在主显示器顶部居中显示固定工具栏，不支持拖动或自动吸附。工具栏包含：

- 箭头工具。
- 矩形工具。
- 文字工具。
- 颜色选择。
- 线宽选择。
- 撤销。
- 清空全部。
- 完成绘图。

首次进入绘图模式时默认选择箭头。后续在同一次应用运行期间保留最后使用的工具、颜色和线宽。

### 5.8 `AnnotationStore`

- 保存当前会话的标注数组。
- 保存当前工具、颜色、线宽和可见性。
- 提供添加标注、撤销、清空和撤销清空操作。
- 数据只存在内存中，应用退出时直接销毁。
- 不依赖 AppKit 窗口对象，以便单元测试。

## 6. 数据模型

`Annotation` 是以下三个不可变值类型之一：

- `ArrowAnnotation`：起点、终点、颜色、线宽。
- `RectangleAnnotation`：标准化矩形、颜色、线宽。
- `TextAnnotation`：左上角位置、文本、颜色、固定字体信息。

位置和尺寸使用主显示器覆盖视图中的 AppKit point 坐标。工具栏显示 2、4、8 三档线宽；内部按 2、4、8 AppKit point 存储，由窗口 backing scale 转换为 Retina 像素，确保视觉尺寸在不同缩放设置下保持一致。

颜色固定为：

- 红色。
- 黄色。
- 绿色。
- 蓝色。
- 白色。
- 黑色。

矩形只绘制边框，不填充。箭头由主线段和终点箭头尖组成。文字使用 macOS 系统常规字体，固定为 24 point；文字颜色使用当前选中颜色。

## 7. 状态模型

应用只有三个覆盖状态：

1. `hidden`：覆盖窗口不可见；没有标注或用户主动隐藏标注时使用。
2. `passThrough`：标注可见，工具栏和红色边框不可见，覆盖窗口不接收鼠标事件。
3. `drawing`：标注、工具栏和红色边框可见，覆盖窗口接收绘图输入。

状态转换规则：

- 应用启动时为 `hidden`。
- 从任何非绘图状态进入绘图模式时切换到 `drawing`，并自动显示已有标注。
- 从 `drawing` 退出时，如果已有标注则切换到 `passThrough`，否则切换到 `hidden`。
- 用户选择“隐藏标注”时切换到 `hidden`。
- 用户选择“显示标注”时，有标注则切换到 `passThrough`，无标注时保持 `hidden`。
- 清空全部后，如果正在绘图则保持 `drawing`；否则切换到 `hidden`。

## 8. 用户交互

### 8.1 进入与退出绘图

- `Command + Shift + D` 和菜单栏“开始／结束绘图”执行相同动作。
- 进入绘图时显示顶部工具栏和一圈红色屏幕边框。
- 退出绘图时隐藏工具栏和边框，保留标注并启用鼠标穿透。
- 退出时取消尚未提交的拖动图形和未确认文字。
- 退出后尝试恢复进入绘图前的前台应用焦点。

### 8.2 箭头

- 鼠标按下确定起点，拖动显示预览，抬起提交终点。
- 箭头可向任意方向绘制。
- 起终点距离小于 4 point 时不创建标注。
- 箭头尖端按线宽成比例计算，并在不同方向保持一致外观。

### 8.3 矩形

- 鼠标按下确定第一个角，拖动显示预览，抬起提交对角。
- 支持从任意方向拖动，提交时将几何数据标准化为正宽高矩形。
- 宽或高小于 4 point 时不创建标注。

### 8.4 文字

- 选择文字工具后，点击画布位置显示单行内联输入框。
- `Enter` 提交非空文字。
- `Escape` 取消输入。
- 仅包含空白字符的文字不提交。
- 切换工具、退出绘图模式或开始另一处文字输入时，取消尚未确认的文字。
- 输入期间应用自身输入框可临时获得键盘焦点；提交或取消后回到绘图状态。

### 8.5 撤销与清空

- 绘图模式下，`Command + Z` 和工具栏撤销按钮移除最近一次已提交操作。
- 添加一个箭头、矩形或文字各算一次操作。
- “清空全部”作为单独的一次可撤销操作，撤销后恢复清空前的全部标注。
- 不实现重做。

## 9. 权限、隐私与本地行为

- 不请求辅助功能权限。
- 不请求屏幕录制权限。
- 不请求麦克风、摄像头、位置或通讯录权限。
- 不读取其他应用内容。
- 不发起网络请求。
- 不保存标注或日志文件。
- 开发诊断仅使用 macOS Unified Logging，不包含其他应用内容或用户输入的文字正文。

## 10. 错误和边界处理

- 全局快捷键注册失败时显示明确提示，同时保留菜单栏“开始绘图”入口。
- 通过应用配置禁止多实例；重复打开时激活现有实例。
- 主显示器分辨率或缩放变化时不迁移现有标注坐标；下次进入绘图模式时重新适配覆盖窗口。首版把运行中改变主显示器配置列为已知限制。
- 正在拖动图形时退出绘图，未完成图形不提交。
- 正在输入文字时退出绘图，未确认文字不提交。
- 隐藏状态进入绘图时自动恢复已有标注。
- 应用退出时不提示保存，直接丢弃全部标注。
- 无法覆盖的全屏游戏、系统安全界面和受保护窗口记录为兼容性限制，不尝试绕过系统限制。

## 11. 测试策略

### 11.1 自动化单元测试

- 箭头、矩形和文字创建。
- 正向与反向拖动产生相同标准化矩形。
- 小于最小尺寸的箭头和矩形被忽略。
- 箭头尖端几何计算。
- 六种颜色与三档线宽应用。
- 按提交顺序撤销标注。
- 清空全部作为一次操作并可撤销恢复。
- `hidden`、`passThrough` 和 `drawing` 状态转换。
- 退出绘图时取消未完成图形和未确认文字。

### 11.2 手动界面验收

1. 在 Apple Silicon、macOS 13 或更高版本双击 `.app` 能启动。
2. 应用只显示菜单栏图标，不显示 Dock 图标。
3. 启动时不出现辅助功能或屏幕录制权限请求。
4. `Command + Shift + D` 能进入和退出绘图模式。
5. 绘图模式显示顶部居中工具栏和红色边框。
6. 能在主显示器上从任意方向绘制箭头和矩形。
7. 能点击位置输入单行文字，`Enter` 确认，`Escape` 取消。
8. 六种颜色和三档线宽均可使用。
9. 退出绘图模式后标注继续显示，鼠标可以操作下方应用。
10. 菜单栏能够隐藏／显示标注、清空和退出应用。
11. `Command + Z` 能撤销普通标注和“清空全部”。
12. 在普通应用窗口及至少一个 macOS 标准全屏应用中完成验证。
13. 快捷键冲突时出现明确提示，菜单栏入口仍可工作。
14. 退出并重新启动后不恢复上一会话标注。

### 11.3 构建验收

- 单元测试全部通过。
- Debug 和 Release 配置均可构建 arm64 应用。
- 构建输出没有编译错误或警告。
- 产出完整 Xcode 工程、Swift 源码和可双击运行的本地 `.app`。
